三种方法都先完成 Rollout，再用固定的 Old Policy 基准优化 Actor。对比关键不是“有没有逐 Token Loss”，而是 Advantage 来源、Actor 更新方式、Critic 与 KL 的角色。

两条容易混淆的概念

① Old 与 Reference：Old 是本批 Rollout 的快照，每批都会刷新；Reference 通常是整个 RL 期间冻结的 SFT 模型。TRPO 的 KL 比较 Old/Current；带 Reference KL 的 GRPO 比较 Reference/Current。

② PPO 与 GRPO 的 Token Loss：二者在 LLM 训练都可能做 Token-level IS、Clip 和 Gradient。PPO+GAE 可为每个 Token 估计不同 Advantage；原始 GRPO 通常把整个 Response 的 Group Advantage 广播到每个 Token。
