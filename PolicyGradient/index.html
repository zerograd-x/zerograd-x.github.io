核心问题 / 哪些动作值得强化？
ĝ = ∑t wt ∇θ log πθ(at | st)

方向来自 log probability，
权重来自对未来回报的判断。

正权重 → 提高采样动作的倾向
负权重 → 降低采样动作的倾向
这是局部梯度直觉，共享参数下不保证每个概率都同向改变。
01 / 先把约定说清楚

先选目标，再写 ψₜ。

本页采用有限时域、起点折扣目标

J(θ) = Eτ∼πθ[ ∑t=0…T−1 γᵗ rₜ ]
Gₜ = ∑k=t…T−1 γk−t rₖ

rₜ 是执行 aₜ 后收到的奖励，sT 是终止状态；0 ≤ γ ≤ 1。有限时域下，状态包含时间 t，或者将 V、Q 写成 Vₜ、Qₜ。本页省略下标。

假定环境与初始状态分布不依赖 θ；动作由当前策略采样（on-policy）。Qπ(s,a) = E[Gₜ | sₜ=s,aₜ=a]，Vπ(s) = E[Gₜ | sₜ=s]，Aπ = Qπ − Vπ。

通用形式里的折扣放在哪里？

∇J = E[ ∑ₜ ∇ log πθ(aₜ|sₜ) ψ̃ₜ ]

若用无外部折扣的通用公式，则 ψ̃ₜ 就是本页的最终权重 wₜ。若采用 ∑ₜ γᵗ ψₜ ∇logπ 的形式，方法 2–6 的 ψₜ 分别为 Gₜ、Gₜ−b、Q、A、δ。

方法 1：wₜ = G₀。整条折扣回报已经相对于起点定义，不能再直接乘 γᵗ。γ>0 时可形式化写 ψₜ=γ−tG₀；γ=0 时直接用 wₜ。

γ=1 时两种写法一致。若用折扣状态访问分布采样，γᵗ 可被采样分布吸收（还可能差一个常数）；均匀抽取时间步时，不能直接声称省略它仍是本页目标的精确梯度。

为什么可以换权重？展开三个关键等式

轨迹概率的 score 是 ∇log pθ(τ)=∑ₜ∇logπθ(aₜ|sₜ)。对 J 使用 likelihood-ratio identity，得到 E[G₀∑ₜ∇logπ]。过去奖励与当前动作无因果关系，其 score 期望为零，留下 γᵗGₜ。

再条件化：E[Gₜ∇logπ | sₜ,aₜ] = Qπ(sₜ,aₜ)∇logπ。对不依赖当前动作的固定 baseline，Ea∼π[b(s)∇logπ(a|s)] = b(s)∇∑ₐπ(a|s)=0。

Bellman 等式给出 E[rₜ+γ(1−dₜ)Vπ(sₜ₊₁)−Vπ(sₜ) | sₜ,aₜ] = Aπ(sₜ,aₜ)。因此准确 V 下的一步 TD residual 是 advantage 的条件无偏样本。

05 / NETWORK & AUTOGRAD

参数共享可以，梯度路径要清楚。

独立网络 · 本页代码采用

s → Actor MLP θ → logits → Categorical → a
s → Value MLP φ → V̂(s)
s → Q MLP ω → 每个动作的 Q̂ → gather(a)

方法 1–2 只用 Actor；方法 3 可用固定 baseline，也可用 V 网络；4 用 Q；5 的示例同时用 Q 与 V；6 用 V。两个隐藏层或更深网络并不是方法定义的一部分。

本例 Actor：3 维时间 one-hot → Linear(3,32) → Tanh → Linear(32,2) → Categorical。V head 输出 1 个标量；离散 Q head 输出动作数个标量。连续动作可用 (s,a) 输入的 Q 网络与高斯 Actor。

共享骨干 · 可选实现

s → encoder η → h
h → policy head θ → logits
h → value head φ / Q head ω → 预测

方法 3–6 可共享骨干；方法 1–2 没有 Critic 需要共享。联合损失 L=LActor+cᵥLV+cqLQ。权重 detach 后，Actor 梯度仍通过 policy head 回到 encoder；Critic 损失也更新 encoder。

stopgrad 不会冻结整个骨干。它只切断权重支路。共享参数应使用一个优化器，对组合 loss 一次 backward/step，避免两个优化器重复更新同一参数。Critic 更新可能改变策略，因此它不再是纯 Actor 梯度的一次更新。

终止、截断、拟合 baseline 与 loss 数值：四个常见陷阱

真正终止令 d=1、下一状态价值为 0。若只是采样器时间限制截断、任务本身仍继续，d=0 并 bootstrap；但若有限时域本身就是目标终点，应当终止。MC 回报需要完整后缀，截断时加估计尾值会引入近似。

无偏 baseline 论证要求其在当前动作采样时已固定，或至少给定状态后不依赖该动作。用同一小批次先拟合再给该批次作权重，或直接减同批均值，可能产生统计依赖和有限样本偏差。示例用更新前预测，Actor 更新后再拟合 Critic。

Actor loss 是梯度代理，不是实际性能指标；值为负或持续下降不意味着真实回报提高。权重标准化、熵奖励、梯度裁剪均会改变更新；本页不加入这些技巧。

多条轨迹应对轨迹求和后按 episode 数取均值。若按所有时间步平均，在变长 episode 下会改变样本加权。历史数据来自旧策略时，不能不加修正地当作 on-policy 数据。

本例的三个边界

方法 4、5 的 Q target 是完整 MC 回报 Gₜ；没有 bootstrap。若改为 on-policy Expected SARSA，可用 sg[rₜ + γ(1−dₜ)∑ₐ πθ(a|sₜ₊₁)Qω(sₜ₊₁,a)]，也可采样下一动作。DQN 则用 max 的最优控制 target；Q Critic 与 DQN 不是同一算法。

方法 6 的 target 只看一步，即使本框架为统一比较而收集完整 episode，也仍是一步 TD。dₜ 只表示真正终止；实现只在非终止 next state 上计算 V。一般外部截断不应置 d=1。本例三步就是任务终点；共享 rollout 拒绝不完整截断，避免把 MC 尾值错误置零。

所有权重取自本轮更新前的网络，采样期间参数固定。每轮 Actor 更新一次、所需 Critic 更新一次，然后重新采样；无 replay、无多轮复用旧轨迹。近似 Q / TD 的 Actor 梯度可能有偏差。
