About this site

Hi, I’m Junyu Wang.

I’m a software engineer working on AI systems, with a background in machine learning, ranking, and large-scale distributed serving.

LLMExp is my independent space for studying and sharing how large language model systems work—from algorithms and inference to reinforcement learning and agent evaluation. I write about the implementation details, trade-offs, and experiments behind the ideas.

You can find more about my professional background on my personal website ↗.

Areas of interest

LLM inference, constrained decoding, reinforcement learning, and agent evaluation.

Open to technical discussion

Questions, corrections, alternative approaches, and reproducible experiments are welcome. Contributions can start with an issue or a pull request on GitHub.
