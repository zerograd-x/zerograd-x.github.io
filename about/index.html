About LLMExp

I work on AI systems, with a background in ranking, machine learning, and large-scale serving.

I started LLMExp to keep track of what I learn while digging into LLM systems. I'm interested in the details that change how a system behaves: memory access, scheduling, decoding, training loops, and evaluation. When a concept is hard to explain in text, I try building a small interactive version.

What I’m working through

Constrained decoding and inference performance; reinforcement learning algorithms; and how to evaluate agents in ways that resemble real use.

Corrections welcome

If something looks wrong, or you've run an experiment that contradicts a claim here, I'd like to know. An issue on GitHub is the easiest way to reach me.
