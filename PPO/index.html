ACTOR-CRITIC · TRAIN STEP BY TRAIN STEP

PPO：从架构到每一个 Train Step

用 Rollout、Critic/GAE、Old Log Prob、IS Ratio、Clipping、KL Monitoring、Adam 串起真正的一次更新。

一句话：PPO-Clip 保留 TRPO 的 Advantage 与 IS，但用分段的 Clipped Objective + 一阶 Adam，替代 CG、KL 约束与 Line Search。Clip 不是硬约束。

ARCHITECTURE

Actor 与 Critic 两个可训练网络

Environment → Old Actor Rollout → (state, action, reward, old_log_prob)
↓
Critic φ

V(s) → TD Error → GAE At → 固定的训练权重 + Return Target。

Actor θ

对旧 actions 重新算 log probability → IS → Clip → Actor Loss。

↓
Actor Adam + Critic Adam → Next Rollout

数据形状：states [T,state_dim]；actions [T]；old_log_probs [T]；advantages [T]。对 LLM PPO，T 可以视为 batch × token 的有效位置数。

01 / COLLECT

先采样，不要边采样边改变 Actor

with torch.no_grad():
    probs = actor(state)                     # [action_dim]
    dist = torch.distributions.Categorical(probs)
    action = dist.sample()
    old_log_prob = dist.log_prob(action)
# state, action, reward, next_state, terminated, truncated

这里 actor 是 Rollout 时刻的策略。在本轮全部 PPO optimizer steps 中，old_log_probs 必须固定。

02 / ADVANTAGE

Critic Forward + GAE：每一步自己的 Advantage

先计算 δt = rt + γV(st+1) − V(st)，再从后往前计算 At = δt + γλ At+1；Episode 边界需要重置。

with torch.no_grad():
    values = critic(states).squeeze(-1)
    next_values = critic(next_states).squeeze(-1)
    deltas = rewards + gamma * next_values * bootstrap_mask - values
    gae = torch.zeros_like(deltas[0])
    advantages = torch.zeros_like(deltas)
    for t in reversed(range(len(rewards))):
        gae = deltas[t] + gamma * lam * continuation_mask[t] * gae
        advantages[t] = gae
    returns = advantages + values   # Critic 的 lambda-return target

注意：bootstrap_mask 在真正终止时为 0；continuation_mask 在 Episode 结束（包括截断）时为 0。为了简化上面只展示独立 Transition 的 GAE 递推。

假设 δ=[1, 2, 3]，γ=0.9；第一步 A₁ = 。λ 决定未来 TD errors 传播权重。

03 / SNAPSHOT

Old Policy：本轮优化的固定分母

old_log_probs = rollout_old_log_probs.detach()
# 不能每个 epoch 都用 actor 重新覆盖 old_log_probs

Old Policy 并不是长期冻结的 SFT Reference。下一次 Rollout 会刷新 Old 的基准。

04 / IMPORTANCE SAMPLING

为什么 Actor 还没变 Ratio 却有 Gradient？

probs = actor(states)
dist = torch.distributions.Categorical(probs)
log_probs = dist.log_prob(actions)
ratio = (log_probs - old_log_probs).exp()  # [T]
surr1 = ratio * advantages

第一次更新前 Ratio=1，但它仍是 θ 的函数，导数不为零。IS 将旧策略采集的 Action 重加权用于当前策略的 surrogate optimization；单步 Ratio 并不完整校正 state occupancy shift。

05 / CLIPPED LOSS

梯度进入平坦区，而非拒绝本次 Adam 更新

surr2 = ratio.clamp(1 - eps, 1 + eps) * advantages
actor_loss = -torch.minimum(surr1, surr2).mean()

A>0 且 Ratio>1+ε 时，不再奖励继续增加该 Action 的概率；A<0 且 Ratio<1−ε 时，不再奖励继续降低其概率。其他样本仍可能改变共享参数。

06 / VALUE LOSS

Critic 学 Returns，不使用 IS Ratio

values_pred = critic(states).squeeze(-1)
critic_loss = torch.nn.functional.mse_loss(values_pred, returns.detach())

Critic 的 Target 来自 Rollout 期间计算的 GAE/Returns，并在这轮多次 Actor Update 中保持固定。Actor/ Critic 参数独立时，先更新谁不是算法要求。

07 / OPTIMIZE

在同一批数据上做若干 Epoch

for epoch in range(ppo_epochs):
    # 重新算 current_log_probs / ratio / clipped_loss
    actor_optimizer.zero_grad()
    actor_loss.backward()
    actor_optimizer.step()

    # Critic 重新 forward，用固定 returns 回归
    critic_optimizer.zero_grad()
    critic_loss.backward()
    critic_optimizer.step()
# 注意：上面两种 loss 每个 epoch 都需要重新 forward，
# 不能重用已经 backward 的旧计算图。

实际训练将 Batch 切成 Minibatches，并逐个重新执行 Loss Forward + Backward。Adam 学习率和 Clip ε 是两个不同的超参数。

08 / OPTIONAL CHECK

这里 KL 是 Old vs Current，通常只做监控

with torch.no_grad():
    log_ratio = new_log_probs_after_step - old_log_probs
    ratio_after = log_ratio.exp()
    approx_kl = (ratio_after - 1 - log_ratio).mean()
    if approx_kl > target_kl:
        stop_further_epochs = True

这是 Old 采样下 KL(Old || Current) 的一个估计形式，计算时需要使用 Adam 更新之后重新 forward 的 log_probs。它不能撤销已执行的 Step。
